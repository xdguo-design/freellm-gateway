# 停用状态颜色设计

## 目标

将管理界面中“停用”状态从绿色健康色中分离出来，使用中性灰蓝色，避免用户把“健康 · 停用”误认为仍处于启用状态。

## 方案

- 前端为 `enabled=false` 的状态标签增加独立 `disabled` 类。
- `.disabled` 使用灰蓝色文字与边框；启用且健康的 `.ok`、失败/限流状态颜色保持不变。
- 同一状态类同时覆盖模型池、健康监控和 Provider 模型列表，后端接口与数据结构不变。

## 验收标准

1. 停用状态渲染为 `disabled` 类，不再使用 `ok` 类。
2. 页面包含灰蓝色的 `.disabled` 样式。
3. 启用且健康的状态仍使用 `ok` 类。
