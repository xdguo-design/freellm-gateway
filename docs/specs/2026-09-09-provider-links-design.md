# Provider 链接展示设计

## 目标

将“公开注册链接”和“文档链接”从可编辑文本框改为可点击链接，避免用户误以为需要填写或修改这些目录元数据。

## 方案

- 添加模型弹窗保留 `public_url` 和 `public_docs_url` 两个隐藏表单字段，确保现有保存 API 和数据结构不变。
- 使用可点击的 HTTPS 链接展示当前值，并在无有效链接时显示“未提供”。
- 选择目录 Provider 时沿用现有自动回填逻辑；选择本地 Provider 时显示其官网链接，文档链接为空。
- 编辑已有模型时展示已保存的链接，不自动覆盖用户已有数据。

## 验收标准

1. 弹窗中不再显示这两个 URL 的文本输入框。
2. 目录 Provider 的注册链接和文档链接可点击并在新标签页打开。
3. 保存新增或编辑模型时，两个 URL 仍按原字段提交。
4. 无链接或非 HTTPS 地址不会生成可跳转链接。
